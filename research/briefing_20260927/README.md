# 晨间简报模式：无损结构化样例

原文来自用户粘贴，未独立核验其中事实。raw.txt 完整保留输入；structure.json 为可复算的结构标注，不是新的新闻证据。自动识别栏目、编号条目、增量说明、影响判断、历史类比和下一验证点，全部位置采用 Unicode 字符偏移。

## 信息分层

- 事实候选：保留归属主体、报道日期、来源名称、数字与单位；只有来源名称时保持待原始出处核验。
- 增量：保存“相比前次新增”叙述；没有可对照的历史版本时，不把它变成已验证 novelty 或 surprise。
- 推演：影响判断、箭头机制与条件情景是研究假说；Event→Factor 与 Factor→Asset 仍分开。
- 验证：下一验证点作为待观察条件，不能当作已发生事件。
- 类比与知识卡：保留在原文和结构层；不能把类比当作当前市场事实。
- 持仓：ΔN、成交成本、Δw、自有资本/客户资金分别记录。原文说无法推断 Δw 时保持未知；Form 4 等标签不代替原始申报核验。

当前实现自动保存结构层和规则候选；尚不能可靠完成全部数字实体、嵌套因果和跨段指代抽取，候选主张仍须人工审阅。原文中的 LaTeX 即使格式不完整也不改写；结构 JSON 可用于后续更强提取器。

## 时间与回放

简报自述截至2026-09-27 07:18（北京时间），不等于每条消息的首次公开时间。导入接口默认以实际导入时间记 known_at，发布时间由用户另行提供。此文件没有写入主应用数据库，也没有进入9月21日的周前预测。

## 查看方式

在 News/Event 页面粘贴原文即可保存结构，位于 RawSource.metadata.briefing。独立样例在 structure.json；原文跨度可逐字符验证。该样例只有一个汇编来源，不能因为内含多条 Reuters 标签就满足多来源或三个月覆盖门槛。
